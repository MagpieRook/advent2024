# MagpieRook's Advent of Code 2024 (GoLang Edition)

This is my repository for [Advent of Code](https://adventofcode.com/about) ([2024](https://adventofcode.com/2024)).
I decided to use [Go](https://go.dev/) this year.
For the most part, my solutions will be:

1. Written quickly.
2. Abandoned as soon as they work.

Don't expect clean, optimized code, or (m)any comments explaining why I took certain paths.
Also don't expect any external PRs to be reviewed or merged.
However, if you're interested in hearing more about why I did things a certain way or algorithms used or anything at all, feel free to get in touch.
I might still be able to explain it, or how I would do it better the second time around.

I'm a little late to the party (April Fools of Code?), but decided to upload these solutions for posterity.
Looking forward to 2025!
